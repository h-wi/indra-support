# INDRA 지원 · 개인정보 처리방침

iOS 앱 **INDRA**의 App Store 지원 페이지와 개인정보 처리방침입니다. GitHub Pages로
서비스합니다.

- 지원: `index.html`
- 개인정보 처리방침: `privacy.html`

## 고칠 때

처리방침 원문은 **앱 저장소의 `Docs/PRIVACY_POLICY.md`**입니다. 앱이 무엇을 저장하고
무엇을 내보내는지 바뀌면 그쪽을 먼저 고치고, 같은 내용을 여기 `privacy.html`에도
옮겨야 합니다. 두 곳이 어긋나면 App Store에 제출한 내용과 실제 앱이 달라집니다.

내용이 바뀌면 `privacy.html`의 최종 수정일도 함께 고칩니다.

## 만드는 이유

App Store는 개인정보 처리방침 URL과 지원 URL을 필수로 요구합니다. 앱 저장소가
비공개라 공개된 주소를 따로 둡니다.
